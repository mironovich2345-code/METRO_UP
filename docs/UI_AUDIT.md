# UI Audit — Metro Mini App · v0.1

> Визуальный аудит всех существующих экранов. **Только оценка, без исправлений.**

**Дата:** 2026-08-05
**Сборка:** Next.js 15.5.22, production (`npm run start`)
**Скриншоты:** [`docs/screenshots/v0.1/`](screenshots/v0.1/)

### Методология
Каждый экран снят в трёх контекстах:

| Контекст | Параметры |
| --- | --- |
| **Desktop** | 1366×900, светлая тема |
| **iPhone 15** | 393×852 @3x, светлая тема |
| **Telegram Mini App** | 393×852 @3x, тёмная тема + инъекция `window.Telegram.WebApp` (пользователь «Даниил») |

> ⚠️ **Про нижнюю навигацию на скриншотах.** Снимки сделаны в режиме full-page. Нижняя навигация имеет `position: fixed`, поэтому на длинных страницах она попадает в **середину** изображения — это артефакт способа съёмки, а не баг. В реальном приложении панель закреплена у нижнего края экрана.

## Сквозные наблюдения

1. **Desktop-раскладки нет (by design, но выглядит пусто).** Приложение — mobile-first Mini App: на 1366px это узкая колонка ~450px по центру и огромные пустые поля по бокам, фирменное свечение только вверху. Для Telegram это нормально, но если планируется веб-превью/презентация на большом экране — стоит добавить «телефонную рамку» или центрирующий фон-сцену.
2. **Фиксированная нижняя навигация — «плавающая пилюля».** Сам компонент красивый; на скриншотах в середине — это артефакт full-page (см. методологию). Реальный риск — перекрытие последнего контента (заметно на Profile). Проверить нижние отступы на всех страницах.
3. **Тёмная тема — сильная сторона.** Все экраны корректно и красиво адаптируются (Telegram-контекст), жёлтый акцент отлично играет на почти чёрном фоне.
4. **Единая дизайн-система выдержана:** радиусы 20–24px, крупная жирная типографика заголовков, вторичный серый текст, жёлтый акцент — консистентно везде.
